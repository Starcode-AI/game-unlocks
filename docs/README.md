# Starcode Download Center

## Dateien hinzufügen
1. ZIP- oder 7Z-Datei in `downloads` legen.
2. In `assets/js/config.js` optional in der Dateiliste eintragen.
3. Alles auf GitHub hochladen.
4. Unter Settings > Pages den Branch `main` und `/root` auswählen.

Bei der Suche muss nur der Name eingegeben werden, ohne `.zip` oder `.7z`.

Enthalten:
- mehrere CSS-Dateien
- mehrere JavaScript-Dateien
- eigene SVG-Icons
- ZIP- und 7Z-Suche
- Suchverlauf
- Dark/Light-Mode
- responsive Handyansicht
